## 🌟 Projects Overview

### 🖼️ Task 1: PixelGallery (Responsive Image Gallery)
* **Directory:** [`Task1/`](./Task1)
* **Key Features:**
  - Dynamic category filtering (*All, Nature, Architecture, People, Tech, Travel*) + live instant search.
  - Multi-view layout toggle: fluid **Masonry Grid** vs. balanced **Uniform Grid**.
  - Full-featured **Lightbox Modal** with previous/next navigation, smooth zoom, fullscreen, and image download.
  - Dark / Light theme switcher with local state persistence and responsive mobile drawer.

---

### 🧮 Task 2: SmartCalc Pro (Web Calculator)
* **Directory:** [`Task2/`](./Task2)
* **Key Features:**
  - Token-based mathematical expression evaluator adhering to standard operator precedence (**BODMAS / PEMDAS**).
  - Real-time result preview as you type with instant division-by-zero protection.
  - Scrollable **History Drawer** to recall or reuse previous calculations.
  - Comprehensive keyboard navigation support (`0-9`, `+`, `-`, `*`, `/`, `Enter`, `Backspace`, `Escape`).
  - Adaptive Dark/Light theme switching.

---

### 🌌 Task 3: Developer Portfolio (Futuristic 3D Showcase)
* **Directory:** [`task3/`](./task3)
* **Key Features:**
  - Cyber-minimalist **Cosmic Runtime** theme with ambient particle background canvas.
  - Interactive Project Showcase, Skills matrix, and Education timeline.
  - Integrated **Interactive Terminal** simulation (`help`, `skills`, `projects`, `clear`).
  - Dedicated ATS-friendly **Resume** page and functional contact inquiry form.

---

### 🎵 Task 4: VibePlayer (Modern Music Player Web App)
* **Directory:** [`Task4/`](./Task4)
* **Key Features:**
  - HTML5 Audio Player with custom playback controls: Play/Pause, Next, Previous, Shuffle, Repeat.
  - Dynamic Real-Time **Canvas Audio Waveform Visualizer**.
  - Playlist browsing, search filtering, recent tracks history, and volume slider with mute toggle.
  - Responsive dark-mode interface with glassmorphic floating player bar.
  - Global keyboard shortcuts: `Space` (Play/Pause), `ArrowLeft`/`ArrowRight` (Seek), `ArrowUp`/`ArrowDown` (Volume).

## 🛠️ How to Run Locally

You can run any of the tasks simply by opening their respective `index.html` file in any modern web browser, or by serving them with a local web server:

```bash
# Clone the repository
git clone https://github.com/anjaligenius/codealpha_tasks-.git

# Navigate into the project folder
cd codealpha_tasks-

# Open any task (e.g., Task 1) in your browser:
# On Windows:
start Task1/index.html
# Or serve using Python:
python -m http.server 3000
```
