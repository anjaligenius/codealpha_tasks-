# SmartCalc Pro — Modern Precision Calculator

A modern, high-precision, responsive calculator web application built with vanilla HTML, CSS, and JavaScript. Featuring a safe mathematical expression parser, real-time preview, calculation history, dark/light theme switching, and comprehensive keyboard shortcut support.

## ✨ Features

- **Safe Mathematical Parser**: Custom recursive descent parser handling operator precedence, brackets, percentages, powers, square roots, and basic trig functions.
- **Real-Time Live Preview**: Calculates and displays evaluated answers as you type expressions.
- **Calculation History**: Stores previous calculations with one-click restore and clipboard copy.
- **Theme Support**: Seamless toggle between modern Dark Mode and clean Light Mode.
- **Keyboard Shortcuts**: Complete desktop keyboard support for fast calculations.
- **Responsive Design**: Polished mobile and desktop user interface with ambient glows.

## 🚀 Getting Started

Simply open `index.html` in your web browser:

```bash
# Or start a local server:
python -m http.server 3000
```
Then visit `http://localhost:3000`.
